# 黏土：把服饰道具重新捏出来

用于claymation全身、头像与九宫格。默认交付形态仍遵循主Skill，通常一人物、一画风、九套穿搭的3×3总览；不强制先出试片或等待新的确认。

## 输入与保留范围

原照负责脸形、眉眼鼻口比例、发型和肤色。已确认角色参考负责连续性。已有九套穿搭主题时保持主题、配色和格位，转译服装道具的构造；明确要求重设计主题才换主题。没有既有主题则按人物和目标设计九套，不固定复制本案例衣服。

用成图修正时，锁定已合格的脸部、人物尺度、姿势和布局，重点改衣服鞋包与道具。不要为增加黏土感牺牲五官比例或改变年龄。

## 从真实物件转成可见的黏土结构

| 对象 | 黏土表现 |
| --- | --- |
| 外套、裤装 | 厚压泥片、略不规则圆边、宽浅拇指压褶；没有织物纹理 |
| 口袋、衣领、袖口 | 外贴泥片和厚边，少量手刻凹槽；没有密集针织或缝线 |
| 纽扣、拉链、扣件 | 扁泥粒、简化刻线、圆钝小块；没有精密金属齿 |
| 鞋 | 圆软泥团、压叠鞋底、两三根粗泥绳鞋带；不照搬网布或工业鞋纹 |
| 包、肩带、手柄 | 软厚方泥团、厚包盖、扁泥带与粗泥圈手柄 |
| 耳机、珠串、控制件 | 圆泥盘、逐颗捏出的珠粒、简单彩色小块 |
| 圆筒、卷毯等道具 | 拼接圆柱、盘卷泥条，保留功能辨识但简化零件 |
| 原金属装饰 | 哑光灰色或彩色黏土，避免镀铬高光 |

对应物件才采用相应手法，不为了清单新增道具。细微指纹、工具压痕和拼接缝应支持造型；不把照片表面加噪点当作风格转换，不做脏裂、老化皮肤或夸张疤痕。

暖米色场景、柔和微缩布光和哑光触感为黏土默认，明确背景要求优先。发束可以简化为手塑泥束，脸部纹理克制并保留原比例。

## 提示词与验收

可执行造型/材质文本的唯一维护入口是 [styles.json](styles.json) 中claymation字段，prepare自动注入。额外参考图需清楚区分身份、主题布局、材质用途；其它风格总览只提供主题布局，不作为黏土表面正向依据。

逐格检查脸部一致、主题不变、服装和道具构造变化、全身完整。重点看口袋边、扣件、鞋带、包带和道具接缝；若仍是工业服饰，只改变背景/表面粗糙度，判风格不足并定向修正。不要靠重新加大眼、缩鼻口来提高“可爱感”。


案例图仅用于比较版式、材质和完成度，人物身份始终来自当前用户原照。分发包不包含私人照片，运行时使用当前用户提供的素材。
