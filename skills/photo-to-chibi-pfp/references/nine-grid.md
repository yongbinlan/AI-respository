# 默认输出：九套穿搭总览

用户选择的默认是同一人物、同一画风下九套不同设计，交付一张3×3总览。默认画风Pop Mart；换成其它画风仍使用这套布局，除非用户明确要单张、头像、多画风试图或其它数量。

## 设计和构图

- 原照确定脸形、五官比例、发型、肤色和辨识性特征。九格保持同一人，衣服不同不能连带换脸。
- Agent规划九套服装、鞋包与配饰，在轮廓、层次、口袋、扣件、材质和用途上形成变化，不只九种颜色。可留一格接近原照，其余自由设计；不固定为示例中的九套主题。
- 服装配饰属于默认九套创意设计范围；保持脸部可见，不靠遮脸、染发或改变年龄制造差异。半身未见的下装鞋子注明为设计补全。
- 三行三列，竖幅约3:4，人物尺度一致、间距均匀、各行脚底线稳定。每格全身，发顶、手和鞋底完整，人物与配件不跨格交叠。
- 同一画风与渲染质量贯穿九格。Pop Mart默认黑底棚拍、哑光软胶、局部高光和轻微地面反射；二维、黏土等按该画风的材质与背景规则，不硬套搪胶。
- 默认无编号、标题、文字、水印。一张总览是一个交付图；不能宣称已提供九张独立高清图片。实际宽高核验，不将某次生成尺寸写成永久硬规格。

## 制作与检查

prepare使用deliverable=nine_grid、outfit_mode=series、outfit_variants九项name/design。默认可一次生成整张设计板；若逐张制作则保持同一原照与角色依据，完成后检查实际总览。不要强制额外先生成母版或增加用户确认。

逐格验收：本人脸部关系 → 九格身份/画风一致 → 九套穿搭差异 → 构图完整与缺陷。格数不对、某格换脸、缺鞋或装饰跨格时修复，不能靠缩略图掩盖问题。


案例图仅用于比较版式、材质和完成度，人物身份始终来自当前用户原照。分发包不包含私人照片，运行时使用当前用户提供的素材。
