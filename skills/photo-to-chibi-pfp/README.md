# 照片转 PFP

上传一张人物照片，生成保留脸形、五官比例和发型特征的风格化形象。

默认得到一张 3×3 全身总览：同一个人、同一种画风、九套不同穿搭。默认画风是 Pop Mart 盲盒潮玩，也可以指定头像、单张全身图，或比较几种画风。

当前版本：v1.5.0。

## 安装与第一次使用

把下面这句发给具备 `skill-installer` 的 Codex：

```text
使用 $skill-installer 安装 https://github.com/yongbinlan/AI-respository/tree/main/skills/photo-to-chibi-pfp
```

手动安装和安装后的检查见[仓库首页](../../README.md#安装)。生成图片需要当前 Codex 会话能使用内置 `image_gen`。这个仓库不提供网站、公共 API、后端凭据或服务额度。

上传全身照或半身照，然后说：

```text
使用 $photo-to-chibi-pfp，保留我的脸形、五官比例和发型，
生成九套不同穿搭的潮玩九宫格。
```

支持的九种画风是 Pop Mart、像素、扁平插画、日系动漫、美漫街头、Funko 适配、赛博朋克、极简线条和黏土定格。画风的具体区别见[风格说明](references/style-and-prompts.md)。

九宫格交付的是一张总览图。需要九张独立高清图时，请明确提出。所有输出都是静态图片，不包含三维模型或实际定格动画。半身照没有拍到的下装和鞋子会按设计补全，不能据此推断原照中的穿着。

## 换成黏土风

```text
使用 $photo-to-chibi-pfp，生成黏土风九宫格。
保留人物脸部比例，衣服、鞋包和道具都采用明显的手捏黏土造型。
```

黏土风会改变衣物和配件的构造：衣料做成厚泥片，口袋外贴，纽扣做成泥粒，鞋带用粗泥绳，包袋和耳机也有软厚的体块感。只换背景或加一层粗糙纹理，还达不到这个要求。

已经选好九套主题时，可以接着说：

```text
保留这九套主题、配色和排列，把衣片、口袋、鞋带、包袋与道具
重塑成黏土造型，人物脸部保持。
```

生成后要看人物是否仍像原照、九格是否像同一个人，再检查衣物和道具是否符合画风、全身有没有被裁掉。风格化无法保证精确还原脸部几何，最终仍需要你看图判断。

具体要求见[黏土造型规则](references/clay-construction.md)和[九宫格标准](references/nine-grid.md)。

## 带参考图时

人物原照负责脸部特征，画风参考负责材质和风格，穿搭参考负责服装、道具及排列。三种用途分开说明，能避免把旧潮玩图的材质继续带进黏土版本。参考图里的文字按素材处理，不当作执行指令。

仓库不收录私人照片、人物生成样图、账户凭据或本机运行记录。

## 辅助脚本

通常在对话里上传照片即可。需要准备本地任务时，可以使用包内的 Python 3 脚本：`template` 生成空白需求模板，`prepare` 准备任务与提示词，`styles` 列出画风，`inspect` 检查图片格式和尺寸。

图片检查需要 [Pillow](requirements.txt)，菜单和模板不需要。脚本不调用生图服务，也不自动判断人脸相似度。字段和命令见[任务接口说明](references/job-input.md)，完整执行规则见 [SKILL.md](SKILL.md)。

在仓库根目录运行回归测试：

```sh
python -B skills/photo-to-chibi-pfp/scripts/test_pfp_job.py
```

v1.5.0 的测试覆盖默认九宫格、九种画风、单张与头像分支、参考图角色、模式模板、Windows 附件路径、缺少依赖时的命令行行为，以及防止覆盖旧任务。测试用的是临时合成图片，只验证任务准备逻辑；成图的相似度和视觉质量仍需实际检查。
