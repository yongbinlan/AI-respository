# 工作流自动化 (Automation Workflows)

提供系统化的工作流自动化能力，帮助用户自动化日常重复任务。

## 功能

- **定义工作流**：将复杂任务拆解为多步骤可执行流程
- **条件分支**：根据执行结果选择不同路径
- **循环执行**：批量处理重复任务
- **错误处理**：自动重试、错误捕获和告警
- **日志记录**：记录每次执行结果便于排查

## 使用场景

- 定期数据收集和整理
- 批量文件处理
- 多步骤部署流程
- 报告自动生成和发送
- 日常系统维护任务

## 核心使用方式

### 1. 定义工作流

```markdown
# 工作流名称：XXX 自动化

## 步骤
1. **步骤名称** - 执行操作
2. **判断结果** - 如果成功 → 下一步，如果失败 → 重试/告警
3. ...
```

### 2. 执行工作流

按照定义顺序逐步执行，每个步骤完成后检查结果，记录日志。

### 3. 结果总结

工作流执行完成后输出：
- 执行时长
- 成功/失败步骤统计
- 输出文件位置
- 错误详情（如果有）

## 最佳实践

- 从小型工作流开始，逐步扩展
- 每个步骤保持单一职责
- 添加适当的重试机制
- 保留执行日志便于审计
- 敏感信息不要写入日志
