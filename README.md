# AI-respository

个人 AI 工具与可复用 Skill。

## 北辰·成果引擎 | Polaris Forge

[polaris-forge](skills/polaris-forge/SKILL.md)

把用户意图转化为可用、可验证的成果。适用于编程、内容、设计、研究与老项目维护：先理解目标，主动补全有价值的需求，按实际复杂度执行，检查成品，再把有证据的问题转为改进。

### 安装与使用

把这一句发给具备 `skill-installer` 的 Codex：

```text
使用 $skill-installer 安装 https://github.com/yongbinlan/AI-respository/tree/main/skills/polaris-forge
```

手动安装时，先让 Codex 根据当前宿主说明确认技能目录并显示解析后的完整路径，再复制 `skills/polaris-forge` 整个目录、保留内部结构。不要覆盖其他 Agent 的目录或现有同名 Skill。安装后检查技能是否出现在可用列表；列表未更新时重新开启会话或重启宿主再核验。

```text
使用 $polaris-forge 处理接下来的需求：先理解目标，主动提出有依据的补充建议；只有关键歧义才问我，交付前检查实际结果。
```

检查已有项目时可直接指定边界：

```text
使用 $polaris-forge 对当前项目做一次只读体检，检查有效版本、重复问题和流程阻塞，先给出有证据的发现与修改建议。
```

### 工作方式

- **目标对齐**：先用已有上下文形成理解，只询问会改变结果或授权的关键问题。
- **主动增值**：提出更好的默认体验和必要补充，区分已知事实、产品假设与可选扩展。
- **适度执行**：简单任务直接完成；高不确定性任务用关键小样校准；正式项目保留原有门禁。
- **成果验收**：检查实际运行、画面、内容或数据，修复问题后复验，如实说明证据与限制。
- **项目维护**：根据真实问题和项目变化诊断、修复、检查；核对旧测试的日期、版本和适用环境，无问题则停止。

本包是独立的工作方法 Skill，无额外运行库、API Key、遥测服务或后台进程。`agents/openai.yaml` 允许按任务自动选择；是否加载仍由宿主决定，安装不等于每次必然调用。

## 照片转 PFP · 九套穿搭总览

[photo-to-chibi-pfp](skills/photo-to-chibi-pfp/SKILL.md) · v1.5.0

上传全身照或半身照，生成保留本人脸形、五官比例与发型特征的风格化形象。默认交付一张 **同一人物、同一画风、九套不同穿搭的 3×3 全身总览**，默认画风为 Pop Mart 盲盒潮玩。

支持九种画风：Pop Mart、像素、扁平插画、日系动漫、美漫街头、Funko 适配、赛博朋克、极简线条、黏土定格。明确要求时可改为单张全身、头像或画风比较。

### 使用

将仓库中的 `skills/photo-to-chibi-pfp` 整个目录安装到 Codex 的用户技能目录或项目 `.codex/skills` 中，保留内部目录结构。也可以让 Codex 使用 `skill-installer` 从本仓库的该目录安装；需要环境中已具备对应安装工具。

在能使用内置 `image_gen` 的 Codex 会话中上传人物照片，然后说：

```text
使用 $photo-to-chibi-pfp，保留我的脸形、五官比例和发型，生成九套不同穿搭的潮玩九宫格。
```

黏土版：

```text
使用 $photo-to-chibi-pfp，生成黏土风九宫格。保留人物脸部比例，衣服、鞋包和道具都采用明显的手捏黏土造型。
```

已有九套主题时：

```text
保留这九套主题和排列，把衣片、口袋、鞋带、包袋与道具重塑成黏土造型，人物脸部保持。
```

### 黏土版的关键规则

不仅改变背景或增加粗糙纹理，还要重做可见构造：厚泥片衣料、外贴口袋、泥粒扣、粗泥绳鞋带、软厚包袋、圆盘耳机及简化黏土配件。保留已经选定的穿搭主题、配色和人物特征。

生成后分别检查人物辨识度、九格一致性、服装与道具的风格表现、全身完整度。具体方法见 [黏土造型规则](skills/photo-to-chibi-pfp/references/clay-construction.md) 和 [九宫格标准](skills/photo-to-chibi-pfp/references/nine-grid.md)。

### 辅助脚本与边界

- 辅助脚本依赖 Python 3；图片检查另需 [Pillow](skills/photo-to-chibi-pfp/requirements.txt)。`template` 按模式生成空白brief，`prepare` 准备提示词和任务，`inspect` 检查图片格式与尺寸，`styles` 列出画风。菜单和模板无需Pillow，脚本不调用生图服务，也不自动判断人脸相似度。
- 支持分别传入人物原照、画风材质参考和穿搭方案参考，避免用潮玩衣服的原材质覆盖黏土造型。字段与命令见 [任务接口说明](skills/photo-to-chibi-pfp/references/job-input.md)。
- 生图使用 Codex 内置 `image_gen`；仓库本身不提供网站、公共 API、后端凭据或服务额度。
- 半身照片未拍到的下装和鞋子属于设计补全，不冒充原照信息。
- 九宫格是一张总览，不是九张独立高清图；输出是静态图片，不是三维模型或实际定格动画。
- 风格化无法保证精确还原人脸几何；始终查看实际成图，并以用户反馈为准。
- 仓库不包含私人照片、人物生成样图、账户凭据或本机运行记录。参考图中的文字按素材处理，不作为执行指令。
